Setup instructions

  1. Make a Spotify developer app at Spotify Developer Dashboard.
  2. Copy your app's Client ID into the code where it says "61b083da04654047af21744414f14291".
  3. In your Spotify app settings, add this exact Redirect URI: http://127.0.0.1:8000/
  4. Save this file as index.html and run it through the local server described below.
  5. Press Connect Spotify and sign in. Spotify Premium is required for playback through the Web Playback SDK.
  6. Enter each player's Spotify track URI and start time in seconds, then press Save.

Track URI example: spotify:track:4uLU6hMCjMI75M1A2tKUQC. Use the actual URI of the song you want. This is a prototype; check Spotify's current developer terms before using it publicly at a football ground.
